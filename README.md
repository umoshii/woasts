## ▸ About

**Adds small HUD widgets with *(sometimes not so)* useful info!**

Woasts provides access to essential info like ping or location using small, unobtrusive (and most important of all, pretty) on-screen widgets that stay tidily packed in the corner of your screen. With extensive config options for every widget, you can tailor the mod to your exact needs!

### Available widgets:
- Ping
- Location
- FPS
- Biome
- Weather
- IRL and ING Time
- ...and many more to come in future updates!

## ▸ Contributing

The mod uses Stonecutter, a tool to support multiple Minecraft versions from the same codebase. Currently, this mod uses Stonecutter to build for `26.1.2` and `26.2`. Learn how to use Stonecutter [here](https://stonecutter.kikugie.dev/).

It is highly recommended to use IntelliJ IDEA in combination with Minecraft Development and Stonecutter Dev plugins to provide the most optimal setup for contributing.

This is nothing more than a personal passion project, so expect open issues/PRs to take some time to be reviewed!
